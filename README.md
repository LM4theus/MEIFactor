# MEIFactor
A simple and easy-to-use web application for startups with many questions about taxation, economics, and investments. If you don't have the money to hire an accountant, the application is simple and integrated with AI that reads files such as spreadsheets, documents, and more, generating intelligent results and recommendations, facilitating decision-making.
